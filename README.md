# MathVerse Pro

A colorful premium math learning website for:

- Basic to advanced topics
- Solved question explanations
- Practice exercises
- Mock tests
- Notes and revision material
- Formula library
- Attractive, modern UI

## Run locally

Open `index.html` directly in a browser, or serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project files

- `index.html` — full website structure
- `style.css` — design and responsivity
- `script.js` — lightweight interactivity
